# 📁 Telegram Bot: FileCloud — Техническое Задание

## 🎯 Цель проекта

Создание Telegram-бота, выполняющего роль файлового облака. Пользователи могут загружать файлы, сохранять их в приватном или публичном доступе, искать по тегам, категориям и названию, а также делиться файлами с другими пользователями.

### 🔧 Основной функционал

1. Загрузка файлов

Поддерживаются любые типы файлов, разрешённые Telegram

Файл сохраняется по file_id, file_name, file_size, mime_type

После загрузки пользователь выбирает:

Публичность: Приватный / Публичный

Категорию (из фиксированного списка)

Необязательное описание

Теги (пользователь может ввести свободно)

2. Поиск файлов

По имени файла (LIKE)

По тегам

По категориям

Фильтр: только мои / все публичные

Inline-режим поиска через @bot_name keyword

3. Обзор публичных файлов

Команда /explore

Пагинация

Сортировка: по дате, по популярности

4. Админ-панель /admin

Статистика: кол-во пользователей, файлов, загрузок

Удаление файлов

Просмотр и добавление категорий

Блокировка пользователей

Назначение лимитов на размер файлов (общий и индивидуальный)

5. Пользовательский профиль /me

Список своих файлов

Кол-во загрузок

Общий размер

### 🗄 Структура базы данных (SQLite)

Таблицы:

users: информация о пользователях

categories: список доступных категорий (создаёт админ)

files: список всех загруженных файлов

file_tags: теги, привязанные к каждому файлу

deleted_files: лог удалений (кем, когда, причина)

⚙ Технологии

Язык: Python 3.10+

Библиотека: telebot (pyTelegramBotAPI)

БД: SQLite (с возможностью перехода на PostgreSQL)

# 🧱 Архитектура проекта

```
filecloud_bot/
├── main.py                # Точка входа, запуск бота
├── config.py              # Токен, конфиги
├── db.py                  # Работа с SQLite
├── handlers/
│   ├── commands.py        # Команды (/start, /admin, /explore и т.д.)
│   ├── files.py           # Загрузка и обработка файлов
│   ├── callbacks.py       # Обработка inline-кнопок
│   └── inline.py          # Inline-режим
├── keyboards.py           # Инлайн-клавиатуры
├── utils.py               # Хелперы, например, подсказки тегов
├── schema.sql             # SQL-схема БД
└── init_db.py             # Инициализация базы
```
Назначение модулей:

main.py: инициализация бота, подключение хендлеров, запуск polling

config.py: переменные окружения, токен, настройки

db.py: взаимодействие с базой данных (создание, запросы, обновления)

handlers/: обработчики команд, сообщений, inline callback'ов

keyboards.py: генерация инлайн-клавиатур

utils.py: служебные функции

schema.sql: определение структуры базы

init_db.py: выполнение schema.sql и создание базы SQLite
